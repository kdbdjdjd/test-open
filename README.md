# Мой день

Простое приложение для задач: добавление, отметка выполнения, фильтры и удаление. Данные сохраняются в localStorage браузера.

## Запуск

Нужен Node.js 22 или новее. Зависимостей нет.

```sh
npm start
```

Откройте http://localhost:3000.

## GitHub Codespaces

Нажмите Code → Codespaces → Create codespace on main. После запуска контейнера сервер стартует автоматически, порт 3000 открывается в preview. Если preview не открылся, откройте вкладку Ports и ссылку порта 3000.

Логи сервера: /tmp/test-open-app.log. При необходимости запустите `npm start` вручную.
